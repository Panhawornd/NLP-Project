+Testing and Validation:
+Documentation

Try these settings first. They’re reasonable experiments for short, informal tweets, but they aren’t guaranteed to improve the score:
1. Add bigrams to BoW: set ngram_range=(1, 2). This lets the model learn two-word phrases such as “not happy.”
2. Tune Logistic Regression’s C: try C=[0.1, 0.5, 1, 2, 5]. C controls regularization; the best value depends on the data.
3. Try character n-grams: add a TF-IDF option with analyzer="char" and ngram_range=(3, 5). Character patterns can help with misspellings and informal spelling.
Compare the options using validation macro F1, which gives each emotion equal weight. Keep the test set for the final evaluation only.
